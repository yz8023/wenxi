# 光鸭云盘与阿里云盘

本次在 `0.5.0+53` 源码中增加两个连接器，适用于共用业务层的 Android 与 Windows。需要重新构建、安装客户端后使用。

## 使用方式

在网盘页选择“光鸭云盘”或“阿里云盘”，进入官方网页登录。登录成功后自动验证并加密保存必要凭据。也可通过手动登录粘贴官网的 Token JSON；阿里支持单独的 `refresh_token`，光鸭支持单独的 Access Token，但只有 Access Token 时过期后需要重新登录。

阿里文件列表上方可以选择“资源库”或“备份盘”，默认优先打开资源库。移动和转存时，目标选择页也可切换空间。收藏、播放历史和排队下载都保留原账号与原空间。

| 功能 | 光鸭云盘 | 阿里云盘 |
| --- | --- | --- |
| 网页登录、账号验证、容量 | 支持 | 支持 |
| 令牌续期 | 有 refresh_token 时支持 | 支持轮换 refresh_token |
| 个人目录、完整分页、缩略图 | 支持 | 支持资源库与备份盘 |
| 分享链接、提取码、分享浏览 | 支持，应用内先配置账号 | 支持，应用内先配置账号 |
| 下载、图片查看、原文件播放 | 复用现有下载与预览流程 | 复用现有下载与预览流程 |
| 新建目录、重命名、移动、删除 | 支持 | 支持，删除进入回收站 |
| 创建分享、转存分享 | 支持 | 支持 |

阿里分享文件的下载、预览和播放需要登录，并先转存到账号中的独立临时目录。清理任务持久保存原账号、空间与目录标识；使用结束后，确认目录名称、根目录位置和类型仍匹配，才移入回收站。被用户改名或移动的目录会保留。光鸭分享下载遵守分享本身的下载权限；受限时显示服务端错误。

两者复用原有多连接下载、准备队列、重试、取消与播放器。未新增上传、离线下载任务或阿里转码清晰度选择功能；原文件播放能力取决于既有播放器及服务端提供的地址。

## 协议依据

参考 [BoxPlayer](https://github.com/gaozhangmin/boxplayer/tree/80d1be6d8a17d8b86327d1146492863ffba872aa)，并于 2026-09-24 核对 [光鸭官网](https://www.guangyapan.com/) 与 [阿里云盘官网](https://www.alipan.com/drive) 的公开前端协议。上游 GPL-3.0 许可保留在 `assets/licenses/BoxPlayer-LICENSE.txt` 和第三方声明中。

光鸭采用当日官网的 `https://api.guangyapan.com/userres/v1/` 路径。个人文件列表从第 0 页开始，分享列表采用 `cursor` / `hasMore`；目录类型以 `resType` 为准。与参考项目中较旧的 `/nd.bizuserres.s/v1/` 路径和分享页码处理不同。账号验证和续期使用 `https://account.guangyapan.com/v1/user/me`、`/v1/auth/token` 及官网公开的 client ID。

光鸭网页登录还保留官网的设备签名。账号接口按官方 SDK 规则从签名提取设备标识，文件接口使用 `swangpan_web_device_id`，避免混用两种标识。手动 Token 未附带设备签名时使用官方 SDK 的本地设备格式，并在同一登录内保持稳定。

阿里采用官网 Token 与设备会话协议，账号信息来自 `user.aliyundrive.com/v2/user/get`，续期来自 `auth.aliyundrive.com/v2/account/token`，文件与分享操作使用 `api.aliyundrive.com`。设备密钥每个登录独立生成并加密存储，签名使用 secp256k1、RFC6979 和 low-S，包含实际 recovery ID；未引入 BoxPlayer 的私有 OpenAPI 应用密钥。

网页凭据读取只允许对应官网的 HTTPS origin，在执行脚本前后再次核对页面地址。账号验证候选值在验证期间不覆盖现有账号。并发续期共用结果，正常续期保持账号 revision；账号移除、替换或操作取消后，迟到结果不会覆盖新状态。

文件查询可以使用既有的有限读取重试；转存、新建、删除等变更不因普通网络错误自动重复提交。异步操作等待任务完成并检查子结果；分页缺失、循环分页、转存大小或哈希不符均会报错。下载地址只携带 CDN 所需的 Referer 和 User-Agent。

## 配置与兼容

远程配置增加 `clouds.guangya`、`clouds.aliyun`，本地 `control.json` 与 HTML 编辑器已同步。旧配置不包含这两项时默认开启。本次未更新线上配置或用户已有的 `config.fixed.json`。

旧历史中标记为“暂未接入”的光鸭与阿里分享会升级为可解析分享，并保留原提取码。其他平台的收藏和播放标识保持原格式。

## 验证范围

协议测试覆盖并发续期、账号切换与取消、分页、设备签名、空间选择、下载地址、批量部分失败、异步完成与失败、临时转存和清理。设备签名的固定向量由独立的 python-ecdsa 0.19.2 生成，包含 recovery ID 为 0 和 1 的情况。

界面测试覆盖两个首页登录入口、取消登录、手机与桌面的空间切换、跨空间目标选择，以及网页登录脚本读取前后的导航检查。仓库层测试覆盖排队下载、地址刷新、收藏及临时目录清理的原账号和原空间绑定。

已对两个平台的公开分享简介和分享凭据接口发送不含账号凭据的无效分享查询：光鸭返回 HTTP 200、业务错误 112；阿里返回 HTTP 404、`NotFound.ShareLink`。这只证明接口可达和错误响应格式，不能替代真实账号联调。

本次没有使用真实光鸭或阿里账号，未验证官方验证码、风控、会员权限和实际大文件传输速度，也未生成安装包。验证日志和参考资料保存在本机 `.local/cloud-providers-20260924/`。

最终检查结果：`dart analyze lib test` 无问题；Flutter 全量回归 1,525 项通过，2 项既有的“我的”页面截图失败（基准显示 0.3.47，当前源码显示 0.5.0）。已逐图核对，未更新这两张无关基准。账号、令牌、解析等定向回归 141 项通过，远程配置编辑器 32 项通过；本次入口变化涉及的 6 张网盘页和桌面解析页截图已核对并更新。
