# 网盘链接识别

解析页、剪贴板提示和系统分享共用链接识别规则，支持分享文案、链接和提取码。识别阶段不请求网盘；开始解析后由对应连接器验证分享并读取文件列表。

当前可以识别 14 个网盘来源，其中 12 个支持分享解析。首页“支持类型”按连接器能力生成，包含后续已接入的阿里、光鸭和联通；微云和蓝奏云优享版的个人盘功能不等于分享解析能力。

| 夸克 | `quark.cn` 及子域 | `/s/` 后的字母数字编号 |

| 123 | `123pan.com`、`123pan.cn`、所有 `123` 加数字的 `.com` / `.cn` 域名及子域，含 `share.123pan.*` | `/s/` 或 `/123pan/` 后的编号，不再强制含连字符；保留旧 `sk` 参数兼容 |
| 移动 | `yun.139.com`、`caiyun.139.com` 及子域 | 依次处理 `/w/i/`、`/m/i?`、`linkID`、`/w/`、末级编号和 8 位以上编号兜底，支持 `shareweb/#/…` |
| 天翼 | `189.cn` 及子域 | 网页版 `/web/share?code=…`、手机版 `share.html#/t/…`、`/t/…` 和分享路由内 `code`；`code` 始终作为分享编号 |
| 蓝奏 | `lanzou` 后缀域名族、`lan[zs]o[ux]`，后缀 `.com/.net/.org/.cn`，含子域 | 实际路径至少一个非空片段；支持原有 `i…/b…`、自定义名称、多层路径和中文路径，保留完整 URL |

域名按完整主机名及子域边界匹配。相似域名、用户名位置、查询参数中出现网盘网址，不会让普通站点被判定为该网盘。HTTP/HTTPS、无协议分享链接、中文分享文案与末尾标点均可输入。移动链接里的 `%20/%0A/%0D`、尾部 `/` 和 `/*…` 不再破坏分享编号；清理只用于识别编号，原始 URL 不重写。

| 蓝奏云优享版 | `ilanzou.com` 及子域的 `/s/…` | 识别来源、编号和提取码；提示暂不支持分享解析，可登录个人盘 |

蓝奏自定义路径不再根据 `i/b` 首字母猜测文件类型，而是在读取实际分享页后选择文件或文件夹流程。同次解析复用已读取页面；子目录保存完整路径，刷新失败时不重新暴露旧列表。中文名称不会被首个汉字截断，相邻的「提取码/密码」等标签仍单独提取，兼容没有冒号或与码之间有空格的文案。分享根首页仍不作为有效分享。

## 提取码顺序

1. 读取 URL 查询参数。参数名忽略大小写，按 `pwd → pass → passcode → password` 的顺序选值，与参数在 URL 中的位置无关。
2. 查询参数没有合格结果时，读取 `#` 路由内 `?` 后的参数，使用相同顺序。
3. 再尝试原始 URL 中上述四类参数的正则匹配。
4. 最后读取周围文案中的「提取码 / 密码 / 访问码 / 口令 / pwd」。同一条分享有多个标签时，最后一个合格标签生效；URL 内合格码始终优先。

自动提取码处理会先解码、去空白，再截取上限：普通网盘最多 4 位且结果必须为 4 位，蓝奏最多 12 位。文案正则最多读取 12 位字母数字，普通网盘只接受恰好 4 位的匹配，蓝奏接受 1–12 位。`http/https` 不作为提取码。手动填写仍优先，允许填写实际需要的码，不受自动识别长度限制，也不改 URL。

保留此前可用的 `#abcd`、`#pwd=abcd`、`accessCode`、非天翼 `code`、中文「为/是」和括号格式作为兼容补充。多链接各自按临近文案配码、重复 URL 合并、签名 URL 的路径转义与查询顺序继续保留。剪贴板只保留分享或已支持的下载类型，不保留无关文案；解析页首次选择优先落在网盘分享上，其他链接仍可手动选择。
