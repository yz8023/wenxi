# 光鸭短信登录与 OpenList 网盘接入

版本保持 `0.5.0+53`。源码、参考资料、修改前备份和验证日志位于 `.local/openlist-clouds-sms-20260924/`。

安卓登录的后续问题和修复见 安卓网盘登录修复。下面保留首次接入时的验证记录。

## 使用方式

光鸭默认打开手机号＋短信验证码表单，发送前勾选光鸭用户协议和隐私政策，60 秒内禁止重复发送。未注册号码会按官网流程注册，页面中已有说明。表单下方保留账号密码、网页登录和手动提交；退出或切换方式会取消当前请求，迟到的结果不能覆盖已有账号。只保存登录令牌和手机号，不保存短信验证码。

| 网盘 | 登录方式 | 已接入能力 |
| --- | --- | --- |
| 蓝奏云优享版 | 账号密码；官方网页登录；手动 appToken 或含 appToken/uuid 的 JSON | 容量、个人目录、原文件播放与下载、新建目录、重命名、移动、删除 |
| 腾讯微云 | 官网 QQ/微信登录；手动完整 Cookie | 容量、个人目录、原文件播放与下载、新建目录、重命名、移动、删除 |
| 中国联通云盘 | 官网短信登录；手动 Refresh Token 或完整令牌 JSON | 容量、个人目录、原文件播放与下载、新建目录、重命名、移动、删除；默认家庭云的浏览与下载 |

三家沿用 OpenList 个人网盘驱动的功能范围，暂不支持分享链接解析、创建分享和分享转存。菜单隐藏未支持的分享操作；解析页和剪贴板提示明确说明当前限制，不会把分享页面当成文件下载或反复要求登录。普通蓝奏云仍保留独立的免登录解析入口。

所有网页登录均保留桌面 UA 和原生 DESKTOP 模式。光鸭改用 `https://www.guangyapan.com/#/oauth/login`；该页仍带有官网 `#app` 的 1100 像素最小宽度，因此只在官方 HTTPS 登录路由上注入窄屏布局，离开此路由恢复通用桌面视口。390 像素浏览器实测文档宽度为 390，两个输入框从 x=32 起、宽约 326 像素，手机可以直接看到登录表单。联通使用官网 `https://panservice.mail.wo.cn/h5/wocloud_ai/login`，已确认可以进入短信登录表单。

## 协议与兼容处理

- 光鸭按当前官网脚本依次调用 captcha init、发送验证码、校验验证码和 signin/signup，同一次验证使用同一设备参数。取得令牌后再校验账号，成功后才提交到账号库。安全验证仍由官方页面完成。
- 蓝奏优享按 OpenList 使用 AES-128-ECB 参数，appToken 中冒号保持字面值，其他保留字符正常编码。文件和目录 ID 加类型前缀防止数字 ID 冲突。下载兼容重定向和 JSON 取链，CDN 验证仅有限重试；目录大小为 KiB 取整值，下载交给传输引擎探测真实长度。密码登录的凭据保存在现有加密账号库供令牌过期时重登；网页和手动 Token 不继承旧账号密码。
- 微云实现 QQ、微信和 OpenID Cookie 认证、CSRF 刷新及微信令牌续期。接口按官方的字符串化请求封装发送，分页按文件＋目录总数前进。文件管理补齐父目录与祖父目录；下载只携带服务端返回的文件授权 Cookie。
- 联通按不同 API channel 使用相应 AES-CBC 密钥和 MD5 请求签名。官网登录凭据从 sessionStorage 的 token/refreshToken 获取。文件管理使用列表 id，下载使用 fid 并匹配返回条目。家庭云沿用现有只读规则。
- 登录续期合并并发请求，保留账号修订号和下载归属；换号、删除账号或取消操作后，旧请求不能写回凭据。目录分页有重复页和异常结构检查，避免静默截断；微云、联通的时间字段转换为可读日期。
- 账号、收藏、备份、下载来源、缩略图和连接数设置接入既有体系；新增三家各自的连接数配置默认 64。远程配置编辑器及 control.json 增加 ilanzou/weiyun/wopan，旧配置缺省开启新入口。

## 验证

接口回归使用合成凭据和独立 Node 加密向量，覆盖登录、令牌续期、取消、分页、下载授权、文件管理和账号归属。界面回归检查默认短信入口、协议勾选、重发倒计时、换手机号、登录方式切换、分享限制、首页和文件操作菜单。生产网页登录脚本由 `flutter test --no-pub tool/login_web_scripts_test.dart` 导出并在 Node 隔离环境中执行。

本轮没有连接 Android 真机，没有发送真实短信，也没有使用这三家真实账号验证服务端文件操作；自动化通过不代表所有账号类型和服务端风控情况已实测。最终测试、构建、签名和安装包信息记录于本轮目录的 verification.json。

最终记录：全项目静态分析无问题；全量运行中 1675 项通过，两项 Windows BT/libmpv 用例及其收尾未完成，随后这两项单独复跑通过，合计覆盖 1677 个 Flutter 用例。登录网页脚本 13 项、远程配置编辑器 33 项通过。手机和桌面的首页基准图已经目视核对后更新；“我的”页面旧基准图中的 0.3.47 同步为现有源码版本 0.5.0。
